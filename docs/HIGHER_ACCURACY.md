# 更高精度的方案：从细线 BEM 到圆柱面元

> 本文记录「提升场求解精度」的调研、基准测试与迁移方案。
> 所有数字都可用 `tools/` 下对应脚本复现。

## 一、为什么要换

当前用的是**细线（thin-wire）BEM**：把导体当成一根线电荷，每段只有 1 个未知数（线电荷密度 λ），
自项用解析近似。它有两个代价：

1. **显示尺寸 ≠ 计算尺寸**：边界元按 0.2 mm 细线算，画面上导线画 0.5 mm、电阻壳 1.1 mm。
   画面表面处的场比真实值大 **2.5 倍**（`E ∝ 1/a`）。
2. **元件端点有伪影**：细线在节点处等于"一根线的端点"，端点附近出现 111 V/m 的纵向尖场
   （按节点电位应只有 0.03 V/m），污染端点 2 cm 内的径向能流。

## 二、基准：双平行导线电容

解析解（无限长、半径 `a`、轴距 `d`）：`C' = π ε₀ / ln(d/a)`

参数：`a = 0.2 mm`，`d = 10 mm`，`L = 300 mm` → 解析值 `7.11×10⁻¹² F/m`

| 方法 | 离散 | C' | 误差 | 耗时 |
|---|---|---|---|---|
| 细线 BEM（现状） | 3 mm 段 | 5.34e-12 | **−25%** | 4 ms |
| 细线 BEM（更长 L） | 12 mm 段 | 3.15e-12 | **−56%**（随 L 恶化） | 4 ms |
| 环电荷（r=h=5 mm） | 60 环 | 1.44e-11 | +103% | 3 ms |
| 环电荷（h=0.6 mm） | 500 环 | 7.89e-12 | +11% | 338 ms |
| 环电荷（h=0.3 mm） | 1000 环 | 7.51e-12 | **+5.6%** | 2967 ms |
| **圆柱带面元（h=4 mm）** | **75 带** | **7.17e-12** | **+0.9%** | **40 ms** |
| 圆柱带面元（h=1 mm） | 300 带 | 7.18e-12 | +1.0% | 533 ms |

三个要点：

- **细线法不是收敛慢，是收敛到错的值**（−25% 不再随段数改善），换成正确自项后反而更差（−45%）。
  说明自项与互项的近似不一致，不是调参能解决的。
- **环电荷**能收敛，但要求 `h ≪ a`（环与环之间是空档），1000 个未知数要 3 秒，不实用。
- **圆柱带 + 精确自项**只要 `h ≈ 8a` 就给出 **1%**，75 个未知数 40 ms —— 这是唯一可落地的方案。

残余的 ~1% 是有限长度端部效应（解析值是无限长），不是离散误差。

## 三、为什么圆柱带是对的

直线导体的面电荷在**轴对称**意义下是精确的：σ 只沿轴向变化。
所以「一串圆柱带，每带 σ 均匀」是**精确的参数化**，不是近似——误差只来自：

- 带内 σ 用常数（`h` 越小越准）
- 相邻带之间的近奇异积分（用分片高斯处理）

而细线模型强行假设 `σ` 只在轴线上，物理上就丢了 `1/a` 的细节。

## 四、落地代价：真正的瓶颈不是求解，是"场求值"

`σ` 的求解只要 40–150 ms（一次/每次重建），可以接受。
但**场的逐点求值**是另一个量级：

| | 现状（细线核） | 面元核 |
|---|---|---|
| 每个采样点的代价 | N 段 × 闭式表达式 | N 带 × 8 个高斯点 × 椭圆积分（AGM，~10 次迭代） |
| 相对成本 | 1× | **~80×** |
| 典型采样量 | 5 万–20 万点 | 同样 |

体渲染要采样十几万点，直接换成面元核会从 4 ms 变成 300 ms 以上，不可接受。

### 混合方案（推荐）

```
电荷分布：  圆柱带面元求解         ← 贵，但每次重建只算一次
远场求值：  每带等效线电荷 λ=σ·2πa  ← 与现有细线核同价，多极误差 ~(a/r)²
近表面：    E_s = σ/ε0（局部解析）  ← 精确，且不需要椭圆积分
```

这样既拿到正确的 σ（从而修掉 2.5 倍表面场误差），又不增加逐点求值的成本。

## 五、迁移计划

1. `FieldSolver` 增加 `model: 'wire' | 'band'`：
   - `band` 模式用本文的带面元装配（自项分片高斯 + 互项环核）
   - 未知数从 λ 换成 σ，`netCharge` 校核改用 `Σσ·2πa·h`
2. 场的求值保持细线核，但 `λ_i` 取 `σ_i·2πa`，**并把 `wireRadius` 直接作为 `a`**
   → 显示尺寸 = 计算尺寸，2.5 倍误差消失
3. 表面附近（`ρ < 2a`）改用 `E_s = σ/ε0` 的局部解析式，同时消掉端点尖场
4. 回归验证：
   - 闭合曲面通量 `∮S·n̂dA = −I²R`：当前误差 13%，目标 < 3%
   - 双导线电容基准：当前 −25%，目标 < 3%
   - 端点伪影：当前 111 V/m，目标 < 10 V/m
5. 性能预算：未知数 ~350（`h = 2a`），求解目标 < 150 ms

## 六、结论

| 方案 | 精度 | 可落地 | 结论 |
|---|---|---|---|
| 细线 BEM（现状） | −25% | ✅ | 有明显系统误差 |
| 环电荷 | +5.6%（需 1000 环） | ❌ 太慢 | 只能当参考解 |
| **圆柱带面元 + 混合求值** | **~1%** | ✅ | **推荐** |
